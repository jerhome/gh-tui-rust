# gh-tui-rust

Client GitHub en terminal : parcourir ses repos et leurs pull requests, et faire des revues.
Exécutable : `ghu`.

État : en conception, voir `docs/roadmap.md`.

Authentification : le jeton de [gh](https://cli.github.com/) (`GH_TOKEN`, `GITHUB_TOKEN` ou `gh auth token`).
